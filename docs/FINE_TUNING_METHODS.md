# 📚 Методология Fine-Tuning & Квантования (LLMControl & Uporka)

В данном документе зафиксированы методы эффективного дообучения (PEFT) и калибровочного квантования моделей для локального инференса на GPU (Intel Arc A770 16GB) и CPU.

---

## 1. Методы эффективного дообучения (PEFT)

| Метод | Описание | Когда использовать | Потребление VRAM |
| :--- | :--- | :--- | :--- |
| **LoRA (BF16, `all-linear`)** *(Используется сейчас)* | Добавляет низкоранговые адаптеры ко всем линейным слоям. Базовые веса заморожены в BF16. | Модели до 3–4B параметров (LFM-2.5, Nanbeige, Ling). Дает идеальную точность без потери градиентов. | ~12–14 GB VRAM при batch=2 |
| **DoRA (Weight-Decomposed Low-Rank Adaptation)** | Разделяет веса на амплитуду (magnitude) и направление (direction). Оптимизирует оба компонента. | Когда точность обычной LoRA упирается в потолок на сложных задачах рассуждения. Практически догоняет Full Fine-Tuning. | +10–15% к VRAM относительно LoRA |
| **rsLoRA (Rank-Stabilized LoRA)** | Использует масштабирование $\frac{\alpha}{\sqrt{r}}$ вместо $\frac{\alpha}{r}$. Стабилизирует градиенты при высоких рангах ($r \ge 64$). | Обучение емких адаптеров ($r=64, 128$) под большой пласт новых знаний. | Сопоставимо с LoRA |
| **QLoRA (4-bit Base + LoRA)** | Базовая модель квантуется в NF4/FP4 на лету через `bitsandbytes`, обучаются только LoRA-адаптеры в 16-бит. | Обучение моделей 8B–14B (Ornith 9B, Qwen 9B/14B) на 16GB VRAM. | ~8–10 GB VRAM |
| **GaLore (Gradient Low-Rank Projection)** | Обучает все веса модели (Full Fine-Tuning), но проецирует матрицу градиентов оптимизатора в низкий ранг. | Когда необходимо полное переобучение весов базовой модели без добавления адаптеров. | Экономит до 65% VRAM на состояниях AdamW |

---

## 2. Продвинутое квантование и калибровка (PTQ)

| Метод | Описание | Преимущество |
| :--- | :--- | :--- |
| **GGUF PTQ (`Q8_0`, `Q4_K_M`)** *(Используется сейчас)* | Прямое квантование после слияния LoRA с базой без калибровочного сета. | Быстрая конвертация, идеально для `Q8_0` (потери точности < 0.1%). |
| **GGUF + `imatrix` (Importance Matrix)** | Прогон калибровочного датасета через `llama-imatrix`. Создается карта значимости весов: критичные слои квантуются в 6-8 бит, остальные в 3-4 бита. | Модели `Q3_K_M` и `Q4_K_M` работают на уровне FP16 даже при экстремальном сжатии. Рекомендуется для квантования под CPU. |
| **AWQ / GPTQ** | Защита 1% важнейших весов активаций при 4-битном сжатии. | Высокая скорость инференса на vLLM/SGLang. |

---

## 3. Рекомендуемый стек по классам моделей

1. **Малые модели (1B – 3B: LFM 2.5, Nanbeige, SmolLM):**
   * Обучение: **LoRA BF16 (`all-linear`, r=16, alpha=32)** на Intel Arc A770 (`torch.xpu`).
   * Квантование: **Q8_0** (GPU/CPU) или **Q4_K_M с imatrix** (для минимального веса).
2. **Средние модели (7B – 14B: Ornith 9B, Qwen 9B, Gemma 12B):**
   * Обучение: **QLoRA (4-bit) + DoRA / rsLoRA**.
   * Квантование: **Q4_K_M / Q5_K_M с imatrix**.
